# DQtable / DQscatter / DQbar — 作り直しの設計

前の設計: [2026-09-29 計画](../plans/2026-09-29-dataquery.md)。
実機で数日使ってみて、独自の `|` 構文と専用画面が使いにくかったので、次の 3 点で作り直す。

1. **種類はマクロ名で決める。** `:DQtable` / `:DQscatter` / `:DQbar` の 3 つに分ける。
2. **クエリは空白区切りの AND だけにする。** `|` で句を区切る構文は廃止する。
3. **専用画面（Open ↗）を廃止する。** 代わりにビューの右端に、よく使う操作ボタンを縦一列に置く。

## 全体像

```
┌ {{renderer :DQscatter, #work/nsb seed==0 x:gre-thin y:gre-thick}} ───────────┐
│ [#work/nsb seed==0 x:gre-thin y:gre-thick        ] 27 rows                    │ ← クエリ欄（Enter で確定）
│ ┌──────────────────────────────────────────────┐ ┌──────┐                     │
│ │                                              │ │ X ▾  │ ← 選ぶと x: が書き換わる
│ │        図（plotly 風・ホバー・ドラッグ拡大）       │ │ Y ▾  │
│ │                                              │ │ 色 ▾  │
│ └──────────────────────────────────────────────┘ │ ⟲    │ ← 拡大を戻す
│ ┌ 表（中ボタンでドラッグすると横に流れる）─────────────┐ │ ⤢    │ ← 図を大きくする
│ │ run  seed  gre-thin …                        │ │ CSV  │ ← 表を CSV でコピー
│ └──────────────────────────────────────────────┘ └──────┘                     │
└───────────────────────────────────────────────────────────────────────────────┘
```

| マクロ | 本体 | 右側のボタン |
|---|---|---|
| `DQtable` | 表 | CSV |
| `DQscatter` | 散布図＋畳んだ表 | X▾ Y▾ 色▾ ± ▤ ⟲ ⤢ CSV |
| `DQbar` | 棒グラフ（平均・min–max のひげ）＋畳んだ表 | X▾ Y のチップ ＋Y▾ ⤢ CSV |

スラッシュコマンドは `/DQ table`・`/DQ scatter`・`/DQ bar`。

## クエリ

空白で区切った語は、すべて「かつ」で結ぶ。語は次の 4 種類で、上から順に判定する。

| 語 | 意味 | 例 |
|---|---|---|
| `#tag` `#[[a b]]` `[[page]]` | そのページを参照するブロック（祖先のタグも含む） | `#work/nsb` |
| `key 演算子 値` | 絞り込み。演算子は `== != < <= > >=`（`=` は `==` と同じ） | `seed==0` `gre-interp<0` |
| `名前:値` | 設定（下表） | `x:gre-thin` `sort:-r2` |
| `key` だけ | そのプロパティを持つブロック | `gre-thin` |

- **値の比べ方：** 数値の型の列は数値として比べる。`key==a,b` は「a か b」。`8/16` のような数値リストの列では、`==16` が「16 を含む」になる。空白やカンマを含む値は `"…"` で囲む。
- **範囲：** 何も書かなければグラフ全体。`in here` / `in page` は廃止する。

設定は次の 7 つ。

| 設定 | 意味 | 書かないとき |
|---|---|---|
| `x:` `y:` | 軸。棒グラフの `y:` は `y:a,b` のように複数書ける | 散布図は数値の列の 1 番目と 2 番目。棒グラフは x がカテゴリ・文字列の列の 1 番目、y が数値の列の 1 番目 |
| `color:` | 散布図の色分けと組（凡例の 1 項目が 1 系列）。`by:` があっても `color:` が勝つ（下の「上下限」） | `by:` があれば `by` の値で色分け、なければ 1 色 |
| `sort:key` / `sort:-key` | 昇順／降順で並べ替え。表の見出しのクリックでも書き換わる | アウトラインの順 |
| `by:run` | 同じ `run` の値を持つブロックを 1 行にまとめる（新しい日誌の値が勝ち、食い違うセルには ⚠） | まとめない |
| `labels:on` | 点の名前を図に常に出す | 出さない（ホバーで出る） |
| `err:band` / `err:off` | y の上下限を、帯で描く／描かない（下の「上下限」） | 棒で描く |

- **誤り：** 書き間違いはクエリ欄の下に ^ 印付きで示し、Enter しても保存しない（今と同じ）。

## 上下限（y のばらつき）

1 つのブロックのプロパティに `gre-thin:: 1.27/1.31/1.29` のように値が複数並んでいたり、`by:run` で同じ run のブロックが複数あったりする（seed ごとの結果など）。
散布図はこれを **y の平均 1 点と、y の min–max の縦棒**で描く。**x 方向の棒は描かない。**

```
 y   x が 1 つの組               x が複数の組（±）            x が複数の組（▤ err:band）
 │      ┬                         ┬       ┬                    ░░▒▒▒▒▒▒▒░░
 │      ●  点 = y の平均           ●───●───●  線 = x の順の平均   ●────●────●
 │      ┴  棒 = y の min–max       ┴   ┴   ┴  各 x に棒          ░░▒▒▒▒▒▒▒░░  帯 = min–max
 └──────────────── x
```

- **値が複数とみなす書き方：** `/` かカンマで区切った数値（`1.27/1.31/1.29`、`1.27, 1.31`）。今の数値リストの型（`8/16`）と同じ扱いにする。
- **組：** 組の key は `color:` があればその key、なければ `by:` の key。key の値が同じブロックが 1 組（表は `by:` で従来どおり 1 行にまとめるが、図はまとめる前のブロックを使う）。どちらもなければ 1 行が 1 組。図のブロックにも絞り込みを効かせる。ブロックにない key は、組のブロックどうしで値が食い違わない場合に限り、まとめた行の値で判定する。
- **組の中：** x（セルに値が複数なら平均）ごとに、その x のすべての y の値（セル内の複数値も 1 つずつ）を集める。
  - x が 1 つ：点 1 つ（y の平均）と縦棒（min–max）。y の値が 1 つなら棒なし。
  - x が複数：x の順に平均を線でつなぎ、各 x に点と縦棒。
- **`err:band`（▤）：** x が複数の組だけ、棒の代わりに上限と下限の間を透明色（不透明度 0.2）で塗る（plotly の `fill='tonexty'`）。x が 1 つの組は棒のまま。
- **`err:off`：** 棒も帯も描かない。x が複数の組の線は残す。
- **色：** 組の値そのもの（`color:` があればその値、なければ `by` の値）。値のない行は `(none)` の組。
- **棒グラフ：** 各行をまず平均にし、そのうえで今までどおり、カテゴリごとの平均と行どうしの min–max のひげを描く。`x:` が `by` の key のときは、カテゴリ＝`by` の値で、まとめる前のブロックどうしの min–max をひげにする（まとめた行では 1 本になるため）。
- **ホバー：** 見出し（組の値、つまり `color` の値、なければ `by` の値、どちらもなければブロック名）、x、y の平均・min・max・n を出す。
- **右側のボタン：** 散布図に `±`（棒）と `▤`（帯）の 2 つのオン/オフボタンを置く。2 つは排他で、オンの方が押された見た目（`aria-pressed`、塗りつぶし）になる。

  | ボタン | オンの条件 | オンで押す | オフで押す |
  |---|---|---|---|
  | `±` | `err:` なし（棒） | `err:off` | `err:` を消す（棒） |
  | `▤` | `err:band` | `err:off` | `err:band` |

  次の値はボタンに埋め込まず、**押した時点のマクロの文字列**から決める。描画が古いままでも、押すたびに必ず切り替わる。
- **表：** 書かれたとおりの文字列を出す。数値として並べ替えるときは平均を使う。

## 操作

- **クエリ欄：** Enter で確定し、Esc で元に戻す。何もないところをクリックすると、ブロックの生テキストの編集に入る（今と同じ）。欄にフォーカスがある間は描き直しを保留し（provideUI が innerHTML を差し替えて入力中の文字とフォーカスを消すため）、欄を離れたときに保留分を描く。欄の中で押して外で離したクリック（文字の選択など）は共通の祖先のクリックになり生テキストの編集に入ってしまうので、捕獲段階で止める。
- **畳んだ表：** 散布図と棒グラフの表は、既定で「▸ Table (27 rows)」の 1 行に畳む。押すと開閉する。開閉はマクロに書かない一時的な表示状態で、ブロックごとに覚え、描き直しても残る。点をクリックすると、表を開いてから該当行を強調する。畳んだままでも CSV はコピーできる。DQtable は畳まない。
- **右側のボタン：** すべてマクロの文字列を書き換えるので、状態はマクロに残る。⟲ と ⤢ は例外で、マクロを書き換えない一時的な表示状態にする。
  - X▾ Y▾ 色▾ は、列の一覧から選ぶドロップダウンにする。棒グラフの X▾ はすべての列から選ぶ。`by` の key（表の先頭の列）も軸と色に選べる。色▾ の空欄は、`by:` があれば `by: KEY`（`by` で色分け中）、なければ `none` と表示する。
  - 棒グラフの Y は、今の y の列をチップで並べ、× で外す（最後の 1 つを外すと `y:` が消えて既定に戻る。`y:` を書いていないときの既定の列には × を出さない）。＋Y▾ で、まだ出ていない数値の列を足す（`y:` がなければ既定の列の後ろに足す）。±・▤ と同じく、押した時点のマクロの文字列から決める。
  - ⟲ は拡大と、隠した系列を戻す。
- **表：** 中ボタンを押したまま動かすと、**横だけ**にスクロールする（縦には動かない）。向きはポインタと逆で、右へ動かすと表は左へ流れる（スクロールバーのつまみを動かす向き）。Linux で中クリックが貼り付けやオートスクロールにならないよう、既定の動作は止める。見出しのクリックで `sort:` が切り替わる。
- **図：** ホバーで値を出し、ドラッグで拡大、何もないところのダブルクリックで元に戻す。点のクリックで表の該当行を強調する（組と同じ key の値が同じ行）。ホバーの吹き出しは Logseq の `<body>` 直下に固定配置で出す（`.dq` の overflow や container-type に切られないように）。Logseq のブロックは mouseover などの伝播を止める（React 17 がルートで受けて `stopPropagation`）ので、文書への待ち受けは捕獲段階で行う。見た目は plotly の既定テンプレートのまま。グラフ上にマウスを乗せると出ていたツールバーは、右側のボタンに移す。ホバーの見出しは組の値（`color:`、なければ `by:`）。
- **plotly 風の操作（散布図）：**
  - **軸の端のドラッグ：** x 軸の帯（目盛りの行）の左 1/4 をつかむと x0 だけ、右 1/4 は x1 だけが動き、つかんだ値がポインタについてくる。中央はパン。y 軸も同じで、下端が y0、上端が y1。カーソルは `ew-resize` / `ns-resize` / `move`。端のダブルクリックで、その端の上に入力欄が出る（今の値を目盛りの書式で入れ、全選択）。Enter で反映、Esc か欄の外のクリックで取り消し。数でない値や範囲が逆転する値は無視する。中央のダブルクリックはその軸だけ自動の範囲に戻す。入力欄のキーは Logseq に渡さない。
  - **Ctrl＋ホイール：** 点の大きさ・線の太さ・図の字（目盛りと軸の名前。凡例は除く）を 0.5〜3 倍の間で 1.1 倍ずつ拡大縮小する。ブラウザ／Logseq の拡大は止める。ホイールだけならページのスクロール。
  - **系列のダブルクリック：** 凡例の項目、またはその系列の点・線・帯・棒をダブルクリックすると、その系列を隠す（描かず、自動の範囲からも外す）。凡例の項目は薄く残り、もう一度ダブルクリックで戻る。系列は色分けの値（`color:`、なければ `by:`）。棒グラフでは y の列ごと。
  - 拡大・Ctrl＋ホイールの倍率・隠した系列は、マクロに書かない一時的な表示状態で、同じブロックが描き直されても残る。
- **棒グラフ：** カテゴリ 1 つに最低 56px（y の列が 1 つ増えるごとに 24px 足す。Ctrl＋ホイールの倍率で増減）を取り、足りなければ図を箱より広く描いて横にスクロールさせる。y 軸も一緒に流れてよい。横軸のラベルはカテゴリの幅から余白を引いた幅で折り返す（`<tspan>`。空白と `-` `_` `/` `.` の後で切り、切れ目がなければ文字で切る。字幅は 1 字 8.4px×倍率の概算）。3 行を超えたら末尾を `…` にし、全文は `<title>` に入れる。下の余白は行数に合わせて広げる。
- **描き直しのちらつき対策：** ボタンでマクロを書き換えると、Logseq はブロックを描き直して（`onMacroRendererSlotted`）さらに DB の変更も通知するので、1 回の操作で 2 回描いていた。しかも毎回、まず viewBox で伸縮する仮の図（640×360 の比）を入れてから実寸で描き直すので、高さが跳ねていた。そこで、ブロックごとに最後の幅と一時状態を覚えておき、最初の描画から実寸で描く。データが変わらない再描画（DB 通知の側）は差し込まない。再描画のたびにブロックの文字列を読み直す。
- **CSV：** 今表に出ている行と列を、Logseq の画面のクリップボードにコピーし、「27 rows copied」と知らせる。

## 消すもの

- `|` 構文のパーサ。`in`・`where`・`cols`・`plot`・`from`・`merge by` の各句。
- 専用画面（`src/panel/` 一式、React とその依存）。型を変える UI もなくなる。型は `dataquery/types` ページに書けば従来どおり効く。
- 旧 `{{renderer :dataquery, …}}` は描かない。代わりに「DQtable / DQscatter / DQbar に置き換わりました」という 1 行を出す（公開前なので移行機能は作らない）。

## 残すもの

型の推定と上書き、行の集め方（ページ参照・祖先のタグ・アウトライン順）、`by` によるまとめと ⚠、plotly 風の描画、実寸での描き直し、Logseq の `svg{pointer-events:none}` への対策。

## 確かめ方

- **パーサ：** 単体テストで確かめる。上の 4 種類の語と 7 つの設定、引用符、`#[[a b]]`、誤りの位置。
- **上下限：** 複数値の読み取り（`/` とカンマ）、組ごとの平均・min・max、x が 1 つの組の点と縦棒、x が複数の組の線（x の順）と各 x の棒、横棒を描かないこと、帯は x が複数の組だけ、`err:off` でも線が残ることを単体テストで確かめる。
- **右ボタン・中ボタン・CSV：** jsdom 上の操作テストで確かめる。
- **実機：** `docs/manual-checks.md` を新しい形に書き直し、gyp さんが机で確かめる。
