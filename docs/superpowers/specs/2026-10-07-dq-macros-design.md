# DQtable / DQscatter / DQbar — 作り直しの設計

前の設計: [2026-09-29 計画](../plans/2026-09-29-dataquery.md)。
実機で数日使ってみて、独自の `|` 構文と専用画面が使いにくかったので、次の 3 点で作り直す。

1. **種類はマクロ名で決める。** `:DQtable` / `:DQscatter` / `:DQbar` の 3 つに分ける。
2. **クエリは空白区切りの AND だけにする。** `|` で句を区切る構文は廃止する。
3. **専用画面（Open ↗）を廃止する。** 代わりにビューの右端に、よく使う操作ボタンを縦一列に置く。

## 全体像

```
┌ {{renderer :DQscatter, #work/nsb seed==0 x:gre-thin y:gre-thick}} ───────────┐
│ [#work/nsb seed==0 x:gre-thin y:gre-thick        ] 27 rows                    │ ← クエリ欄（Enter で確定）
│ ┌──────────────────────────────────────────────┐ ┌──────┐                     │
│ │                                              │ │ X ▾  │ ← 選ぶと x: が書き換わる
│ │        図（plotly 風・ホバー・ドラッグ拡大）       │ │ Y ▾  │
│ │                                              │ │ 色 ▾  │
│ └──────────────────────────────────────────────┘ │ ⟲    │ ← 拡大を戻す
│ ┌ 表（中ボタンでドラッグすると横に流れる）─────────────┐ │ ⤢    │ ← 図を大きくする
│ │ run  seed  gre-thin …                        │ │ CSV  │ ← 表を CSV でコピー
│ └──────────────────────────────────────────────┘ └──────┘                     │
└───────────────────────────────────────────────────────────────────────────────┘
```

| マクロ | 本体 | 右側のボタン |
|---|---|---|
| `DQtable` | 表 | CSV |
| `DQscatter` | 散布図＋表 | X▾ Y▾ 色▾ ± ⟲ ⤢ CSV |
| `DQbar` | 棒グラフ（平均・min–max のひげ）＋表 | X▾ Y▾ ⤢ CSV |

スラッシュコマンドは `/DQ table`・`/DQ scatter`・`/DQ bar`。

## クエリ

空白で区切った語は、すべて「かつ」で結ぶ。語は次の 4 種類で、上から順に判定する。

| 語 | 意味 | 例 |
|---|---|---|
| `#tag` `#[[a b]]` `[[page]]` | そのページを参照するブロック（祖先のタグも含む） | `#work/nsb` |
| `key 演算子 値` | 絞り込み。演算子は `== != < <= > >=`（`=` は `==` と同じ） | `seed==0` `gre-interp<0` |
| `名前:値` | 設定（下表） | `x:gre-thin` `sort:-r2` |
| `key` だけ | そのプロパティを持つブロック | `gre-thin` |

- **値の比べ方：** 数値の型の列は数値として比べる。`key==a,b` は「a か b」。`8/16` のような数値リストの列では、`==16` が「16 を含む」になる。空白やカンマを含む値は `"…"` で囲む。
- **範囲：** 何も書かなければグラフ全体。`in here` / `in page` は廃止する。

設定は次の 7 つ。

| 設定 | 意味 | 書かないとき |
|---|---|---|
| `x:` `y:` | 軸。棒グラフの `y:` は `y:a,b` のように複数書ける | 散布図は数値の列の 1 番目と 2 番目。棒グラフは x がカテゴリ・文字列の列の 1 番目、y が数値の列の 1 番目 |
| `color:` | 散布図の色分け | 1 色 |
| `sort:key` / `sort:-key` | 昇順／降順で並べ替え。表の見出しのクリックでも書き換わる | アウトラインの順 |
| `by:run` | 同じ `run` の値を持つブロックを 1 行にまとめる（新しい日誌の値が勝ち、食い違うセルには ⚠） | まとめない |
| `labels:on` | 点の名前を図に常に出す | 出さない（ホバーで出る） |
| `err:band` / `err:off` | 値が複数ある行の上下限を、帯で描く／描かない（下の「上下限」） | 棒で描く |

- **誤り：** 書き間違いはクエリ欄の下に ^ 印付きで示し、Enter しても保存しない（今と同じ）。

## 上下限（1 行に値が複数あるとき）

1 つのブロックのプロパティに、`gre-thin:: 1.27/1.31/1.29` のように値が複数並んでいることがある（seed ごとの結果など）。
散布図・棒グラフはそのような値を、**平均の位置に描き、min–max を上下限として添える**。

```
 y        err:bar（既定）                 err:band
 │      ┬                              平均を x の順に線でつなぎ、
 │  ┬   ●   ┬    点 = その行の値の平均      min–max の間を透明色で塗る
 │  ●   ┴   ●    棒 = その行の min–max     ░░░▒▒▒───●───▒▒▒░░░
 │  ┴       ┴
 └──────────────── x
```

- **値が複数とみなす書き方：** `/` かカンマで区切った数値（`1.27/1.31/1.29`、`1.27, 1.31`）。今の数値リストの型（`8/16`）と同じ扱いにする。
- **散布図：** y が複数なら縦の棒、x が複数なら横の棒を付ける。値が 1 つの行は普通の点にし、棒を付けない。行どうしをまとめることはしない（1 行が 1 点）。
- **`err:band`：** 色ごとに、x の小さい順に平均を線でつなぐ。上限と下限を結んだ帯を、その色の透明色（不透明度 0.2）で塗る。plotly の `fill='tonexty'` と同じ見た目にする。
- **`err:off`：** 棒も帯も描かず、平均の点だけにする。
- **棒グラフ：** 各行をまず平均にし、そのうえで今までどおり、カテゴリごとの平均と行どうしの min–max のひげを描く。
- **ホバー：** 平均・min・max・n を出す。
- **右側のボタン：** 散布図に `±` を置く。押すたびに 棒 → 帯 → なし と切り替わる。
- **表：** 書かれたとおりの文字列を出す。数値として並べ替えるときは平均を使う。

## 操作

- **クエリ欄：** Enter で確定し、Esc で元に戻す。何もないところをクリックすると、ブロックの生テキストの編集に入る（今と同じ）。
- **右側のボタン：** すべてマクロの文字列を書き換えるので、状態はマクロに残る。⟲ と ⤢ は例外で、マクロを書き換えない一時的な表示状態にする。
  - X▾ Y▾ 色▾ は、列の一覧から選ぶドロップダウンにする。
- **表：** 中ボタンを押したまま動かすと、横（と縦）にスクロールする。Linux で中クリックが貼り付けやオートスクロールにならないよう、既定の動作は止める。見出しのクリックで `sort:` が切り替わる。
- **図：** ホバーで値を出し、ドラッグで拡大、ダブルクリックで元に戻す。点のクリックで表の該当行を強調する。見た目は plotly の既定テンプレートのまま。グラフ上にマウスを乗せると出ていたツールバーは、右側のボタンに移す。
- **CSV：** 今表に出ている行と列を、Logseq の画面のクリップボードにコピーし、「27 rows copied」と知らせる。

## 消すもの

- `|` 構文のパーサ。`in`・`where`・`cols`・`plot`・`from`・`merge by` の各句。
- 専用画面（`src/panel/` 一式、React とその依存）。型を変える UI もなくなる。型は `dataquery/types` ページに書けば従来どおり効く。
- 旧 `{{renderer :dataquery, …}}` は描かない。代わりに「DQtable / DQscatter / DQbar に置き換わりました」という 1 行を出す（公開前なので移行機能は作らない）。

## 残すもの

型の推定と上書き、行の集め方（ページ参照・祖先のタグ・アウトライン順）、`by` によるまとめと ⚠、plotly 風の描画、実寸での描き直し、Logseq の `svg{pointer-events:none}` への対策。

## 確かめ方

- **パーサ：** 単体テストで確かめる。上の 4 種類の語と 7 つの設定、引用符、`#[[a b]]`、誤りの位置。
- **上下限：** 複数値の読み取り（`/` とカンマ）、平均・min・max、値が 1 つの行に棒を付けないこと、帯が x の順に並ぶことを単体テストで確かめる。
- **右ボタン・中ボタン・CSV：** jsdom 上の操作テストで確かめる。
- **実機：** `docs/manual-checks.md` を新しい形に書き直し、gyp さんが机で確かめる。
