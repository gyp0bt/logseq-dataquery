# 実機確認（Logseq OG デスクトップ）

準備: `npm install && npm run build` → Logseq の設定 → 詳細 → 開発者モード ON → `t p`（プラグイン）→ Load unpacked plugin → このリポジトリのフォルダを選ぶ。再ビルドしたらプラグインカードの Reload を押す。

設計: [DQtable / DQscatter / DQbar の設計](superpowers/specs/2026-10-07-dq-macros-design.md)。確かめる人は gyp さん。

## M1 DQtable / DQscatter / DQbar

### マクロとスラッシュコマンド
- [ ] `/DQ table`・`/DQ scatter`・`/DQ bar` で、それぞれ `{{renderer :DQtable}}` などが入り、グラフ全体の property 付きブロックが出る。
- [ ] 右端のボタン列が種類ごとに揃っている。表＝CSV、散布図＝X▾ Y▾ Color▾ ± ▤ ⟲ ⤢ CSV、棒＝X▾ Y のチップ ＋Y▾ ⤢ CSV。グラフにマウスを乗せても上にツールバーは出ない。
- [ ] 旧 `{{renderer :dataquery, …}}` のブロックは描かれず、「Data query now uses DQtable, DQscatter and DQbar. …」の 1 行だけが出る。
- [ ] ブロックの幅を狭くする（サイドバーに開くなど）と、ボタン列が図の上に横並びで移る。

### クエリの語
- [ ] `#work/nsb` → そのタグ（祖先ブロックのタグも含む）を持つブロックだけになる。`#[[空白 入り]]` と `[[空白 入り]]` も 1 語として効く。
- [ ] `seed==0`・`seed=0`・`gre-interp<0`・`combine==none,mean`（どちらか）・`note=="8 cells, seed"`（引用符の中の空白とカンマ）が効く。数値は数値として比べる（10 が 9 より後）。
- [ ] `patch==16` が `8/16` の行も拾う（「含む」）。
- [ ] `gre-thin` だけ書く → そのプロパティを持つブロックだけになる。
- [ ] 誤り（`gre-thin<`、`foo:bar`、`x:a x:b`）で Enter → 欄の下に ^ 印とメッセージが出て、保存されない。欄はそのまま打ち続けられる。
- [ ] Enter で保存・Esc で元に戻る。日本語入力の変換確定の Enter では保存されない。欄の外をクリックしただけでは保存されない。

### 設定
- [ ] 散布図で `x:` `y:` を書かない → 数値の列の 1 番目と 2 番目が軸になる。棒グラフは x がカテゴリ・文字列の列の 1 番目、y が数値の列の 1 番目。
- [ ] `x:gre-thin y:gre-thick color:seed` が効き、凡例に色ごとの値が出る。棒グラフの `y:gre-thin,gre-thick` で棒が 2 本ずつ並ぶ。
- [ ] `sort:gre-thin` / `sort:-gre-thin` で昇順／降順。表の見出しをクリックすると なし → 昇順 → 降順 → なし と回り、マクロの `sort:` だけが書き換わる。
- [ ] `by:run` → 同じ run が 1 行にまとまり、食い違うセルに ⚠（マウスを乗せると各値と出典ページ）。
- [ ] 散布図で `by:run`（`color:` なし）→ 点が run の値ごとに色分けされ、凡例に `run = …` が並ぶ。点のホバーの 1 行目が run の値になる（ページ名・ブロック名ではない）。`color:seed` を足すと色分けは seed に変わる。
- [ ] `labels:on` で点の名前が常に出る。既定ではホバー時だけ。
- [ ] `dataquery/types` ページのページプロパティに `gre-*:: ratio` と `seed:: category` を書く → 1.00 の破線と、セルの緑/赤が出る。

### 右側のボタン
- [ ] X▾ Y▾ Color▾ で列を選ぶ → マクロの `x:` などが書き換わる。手で書いたほかの語（空白の数も含めて）はそのまま残る。Color▾ の「none」で `color:` が消える。
- [ ] 棒グラフの X▾ に、文字列・カテゴリだけでなくすべての列が並ぶ。
- [ ] `by:run` の棒グラフで、X▾ に run が並ぶ。選ぶ（`x:run`）→ run ごとに棒 1 本、ひげはその run のブロックどうしの min–max、`n=` はブロックの数。散布図の X▾ Y▾ Color▾ にも（数値なら）run が並ぶ。
- [ ] 棒グラフの Y に、今の y の列がチップで並ぶ。`y:a,b,c` の b の × → `y:a,c` になる。最後の 1 つの × → `y:` が消え、既定の列に戻る。`y:` を書いていないときの既定の列には × が出ない。
- [ ] 棒グラフの ＋Y▾ に、まだ出ていない数値の列だけが並ぶ。選ぶ → その列が `y:` の後ろに足され、棒が増える。`y:` がないときは `y:既定の列,選んだ列` になる。素早く続けて操作しても、毎回そのときのマクロの文字列から書き換わる。
- [ ] y の列を 3〜4 本にした棒グラフで、棒が細くなりすぎず、x のラベルが重ならない（足りなければ横にスクロール）。
- [ ] ± と ▤ のうち、今の状態のボタンだけが塗られている（既定はどちらも塗られない）。± を押す → `err:bar`、もう一度 → `err:` が消える。▤ を押す → `err:band`、もう一度 → `err:` が消える。**素早く続けて押しても、毎回必ず切り替わる**（2 回に 1 回しか効かない、がない）。
- [ ] ± や X▾ を操作したとき、図が一瞬大きくなって縮む・高さが跳ねる・二度描かれる、といったちらつきがない。散布図と棒グラフの両方で確かめる。
- [ ] ⟲ でドラッグ拡大と隠した系列が戻り、⤢ で図が縦に大きくなる。どちらもマクロは書き換わらない。
- [ ] CSV → 「27 rows copied」のように件数が出て、表計算ソフトやテキストに貼ると今の表の行と列が入る（カンマや引用符を含む値も崩れない）。

### 上下限（1 行に値が複数）
- [ ] `gre-thin:: 1.27/1.31/1.29` や `gre-thin:: 1.27, 1.31` の行が、y の平均の位置に点 1 つ、y の min–max の**縦**棒付きで描かれる。値が 1 つの行には棒が付かない。**横の棒はどこにも出ない**（x が `2/4` の行も、x の平均の位置に置かれるだけ）。
- [ ] `by:run` で、x に選んだ変数が run の中で 1 つだけ → run ごとに点 1 つ（その run の全ブロック・全値の y の平均）と縦棒 1 本。表は run ごとに 1 行のまま。
- [ ] `by:run` で、x に選んだ変数が run の中で複数ある → x の順に平均を結ぶ線＋各 x の点＋各 x の縦棒。
- [ ] ▤（`err:band`）→ x が複数の run だけ、棒の代わりに min–max が薄い色の帯になる。x が 1 つの run は棒のまま。ドラッグで拡大しても帯が描画領域の外にはみ出さない。
- [ ] ± も ▤ も切る（`err:off`）→ 平均の点だけ。x が複数の run の線は残る。
- [ ] `by:run color:seed` → 点は **seed の値ごと**に組・色分けされる（run ではない）。凡例は `seed = 0` などで、ホバーの 1 行目も seed の値。点をクリック → その seed の行が表で強調される。
- [ ] `by:` なしで `color:seed` → seed の値ごとに組になる。同じ seed・同じ x の行は平均の点 1 つと min–max の縦棒、x が複数あれば x の順に線でつながる（▤ で帯、± も ▤ も切ると点と線だけ）。ホバーの 1 行目は seed の値。点をクリック → 表のその seed の行がすべて強調される。
- [ ] `by:` も `color:` もない散布図は、今までどおり 1 行が 1 点。
- [ ] `color:seed`（や `by:run`）の散布図で ± も ▤ も切ってある（既定）→ **すべての行が 1 点ずつ**、seed の色で描かれる（まとめられない）。± か ▤ を押したときだけ組の平均と棒・帯になる。
- [ ] 棒グラフの Color▾ で `seed` を選ぶ → `color:seed` が書かれ、各カテゴリに seed の値ごとの棒が並ぶ。凡例は `seed = 0` など。棒のホバーに seed の値が出る。`y:a,b` と一緒なら凡例は `a · 0` などになる。
- [ ] 棒グラフでは各行が平均で数えられる。
- [ ] 点にマウスを乗せる → 吹き出しの 1 行目が組の値（`color:` があればその値、なければ run の値、どちらもなければブロック名）、続いて x、y の mean・min・max・n が出る。表は書いたままの文字列で、並べ替えは平均で並ぶ。

### 表と図の操作
- [ ] 表の上で中ボタンを押したまま動かす → **横だけ**にスクロールし（縦には動かない）、向きはポインタと逆（右へ動かすと表は左へ流れる）。カーソルが掴む形になる。中クリックで選択文字列の貼り付けやオートスクロールが起きない。
- [ ] 長い表は高さ 32em ほどで止まり、中で縦にスクロールする。
- [ ] 表の行リンクをクリック → そのブロックまでスクロールする。
- [ ] 点・棒にマウスを乗せる → **吹き出しが出る**（前回の実機では出なかった）。図の端の点でも吹き出しが切れずに全部見える。Ctrl＋ホイールやドラッグ拡大の後も出る。
- [ ] 散布図・棒グラフの表は、最初は「▸ Table (27 rows)」の 1 行に畳まれている。押すと開き（▾）、もう一度で畳む。± を押す・run の値を書き換えるなどで描き直しても、開閉はそのまま。畳んだままでも CSV はコピーできる。DQtable は畳まれない。
- [ ] 点をクリック → 表が畳まれていれば開き、該当行が強調され、見える位置までスクロールする。`by:run` では run の行が強調される。
- [ ] 図の上をドラッグ → その範囲に拡大。何もないところのダブルクリックで戻る。
- [ ] 散布図の x 軸の目盛りの行の右 1/4 をつかんで左右に動かす → 右端（x1）だけが動き、つかんだ値がポインタについてくる。左 1/4 は x0 だけ、中央はパン。y 軸も同じ（下端＝y0、上端＝y1、中央＝パン）。カーソルが ↔ / ↕ / 十字の移動形になる。
- [ ] 散布図の軸の端（x 軸の左右 1/4、y 軸の上下 1/4）をダブルクリック → その端の上に小さな入力欄が出て、今の値が目盛りと同じ書式で全選択されている。数を打って Enter → その端だけが変わる。Esc か欄の外をクリック → 何も変わらない。`abc` や逆転する値（x0 に x1 より大きい数）は無視される。入力中のキーで Logseq のショートカットが動かない。日本語入力の確定 Enter で反映されない。
- [ ] 軸の中央をダブルクリック → その軸だけ自動の範囲に戻る（もう一方の軸の拡大は残る）。軸の端・中央のダブルクリックで、図全体の拡大が戻ったり系列が隠れたりしない。
- [ ] 図の上で Ctrl＋ホイール → 点・線・目盛りと軸の名前が大きく／小さくなる。**凡例の大きさは変わらない。**Logseq の画面全体は拡大しない。ホイールだけならページがスクロールする。
- [ ] `color:seed` の散布図で、凡例の `seed = 0` をダブルクリック → その色の点（と棒・帯）が消え、軸の範囲が残りの点に合わせて変わる。凡例の項目は薄く残り、もう一度ダブルクリックで戻る。点や帯をダブルクリックしても同じ。棒グラフの凡例（y の列）でも同じ。
- [ ] 拡大・Ctrl＋ホイールの倍率・隠した系列が、± を押す・run の値を書き換えるなどで描き直されても残る。
- [ ] カテゴリの多い棒グラフ（30 個ほど）で x のラベルが重ならず、図の部分が横にスクロールする。スクロールした状態でも吹き出しが正しい棒に出る。
- [ ] 長いカテゴリ名（`mesh-fine_v2/run.a` のような名前や、空白を含む長い名前）の棒グラフ → ラベルがカテゴリの幅で折り返され（`-` `_` `/` `.` や空白の後で切れる）、隣のラベルと重ならない。3 行を超える名前は末尾が `…` になり、ラベルにマウスを乗せると全文が出る。下の余白が広がり、`n=` の行がラベルと重ならない。Ctrl＋ホイールで拡大しても重ならない。
- [ ] ビューの何もないところをクリック → ブロックの生テキストの編集に入る。クエリ欄・右側のボタン・図・表のクリックでは入らない。
- [ ] **クエリ欄が編集できる**（前回の実機では描画後に編集できなかった）：クリックでキャレットが入る。文字を打てる、マウスで文字を選択できる、日本語入力ができる。Enter で保存、Esc で元に戻る。
- [ ] **ブロックを選択した状態**（ブロックの編集中に Esc を押して、ブロックが青くなった状態）でクエリ欄をクリック → キャレットが入り、文字を打てる。
- [ ] **別のブロックを生テキストで編集中**にクエリ欄をクリック → そのブロックの編集が終わり、欄に打てる。
- [ ] クエリ欄で Esc → 欄が元の文字に戻ってフォーカスが外れる。**ブロックの生テキストの編集に入らない**、ブロックも選択されない。
- [ ] クエリ欄の中で押して欄の外（見出しなど）で離す（文字の選択がはみ出した場合）→ 生テキストの編集に入らない。
- [ ] クエリ欄に打ちかけのまま、別の場所で run の値を書き換える → 欄の文字もフォーカスも消えない。欄を離れる（Esc か欄の外をクリック）と、ビューが新しい値で描き直される。
- [ ] `by:run` の散布図で Color▾ を開く → `run` が選べる。空欄の項目は `by: run` と表示される（`by:` がなければ `none`）。`run` を選ぶとマクロに `color:run` が書かれる。

### 表：画像・列・セルの編集
- [ ] `pic:: ![a](../assets/x.png)` のセル → 縮小画像（高さ 64px、縦横比そのまま）が出る。`![a](..) ![b](..)` は 2 枚並ぶ。`assets/x.png` だけのセル、`https://…/x.jpg` だけのセルも画像になる。`javascript:` などは文字のまま。
- [ ] 画像をクリック → 画面の上に大きく出る。クリックか Esc で閉じる。ページは移らず、生テキストの編集にも入らない。
- [ ] 画像があると右側に Img − ＋ が出る。＋ → `img:80`、もう一度 → `img:100`。− で戻り、64 で `img:` が消える。
- [ ] 画像の上で Ctrl＋ホイール → 表の画像がすべてその場で大きく／小さくなり、止めて少しすると `img:` が 1 回だけ書かれる。Logseq の画面全体は拡大しない。
- [ ] Cols▾ を開く → すべての列（`by:run` なら run も）にチェックが付いている。外す → `hide:列` が書かれて表と CSV から消える。Cols▾ は開いたまま。付け直す → `hide:` から外れる（最後の 1 つで `hide:` が消える）。隠した列も X▾ Y▾ Color▾ には残る。
- [ ] セルをダブルクリック → 書かれた文字列の入った欄が開く。書き換えて Enter → ブロックのプロパティが変わり、表が描き直される（表の横スクロール位置と、畳んだ表の開閉はそのまま）。空にして Enter → プロパティが消える。Esc か欄の外のクリック → 何も変わらない。日本語入力の確定 Enter では保存されない。
- [ ] 別のブロックを生テキストで編集中にセルをダブルクリック → 編集が終わって、セルの欄に打てる。
- [ ] `by:run` の表で、run の中で 1 つのブロックだけが持つ key のセル → 編集できる（そのブロックに書かれる）。2 つ以上のブロックが持つ key、どのブロックも持たない key のセル → 「Cell comes from several blocks; edit the block directly」と出て、欄は開かない。
- [ ] run の列（`by` の key）とブロック名の列はダブルクリックしても欄が開かない。ブロック名のクリックは今までどおりそのブロックへ飛ぶ。
- [ ] 見出しの末尾の ＋ をクリック → 欄が出る。`note` と打って Enter → `note` の列が空で足される（マクロは変わらない）。セルに値を書くと普通の列になる。`Note`・`a b`・既にある列名 → 欄の上に理由が出て、足されない。Esc で取り消し。

### 見た目と追従
- [ ] run の値を書き換える → 1 秒以内にビューが追従する。
- [ ] 図の字と点がはっきり読める（ブロック幅いっぱいに描かれる）。見た目は plotly の既定テンプレートのまま。
- [ ] ライト/ダークを切り替える → 読める配色のまま。
- [ ] 字の大きさが本文や Logseq 組み込みクエリの表と揃っている。
- [ ] 行がアウトラインに書いた順に並ぶ（シャッフルされない）。

## v0.2.0: spreadsheet table (not covered by jsdom tests)

- Full screen (⛶): the view fills the Logseq window; no ancestor clips it. Esc leaves.
- Click a cell, type a letter with a Japanese IME on: the editor opens and the first key is not lost.
- Arrow keys / Tab / Enter in a cell do not move Logseq's block selection or open its editor.
- Drag-select, Ctrl+C, paste into Excel / Sheets: cells land as cells.
- Ctrl+V a screenshot into a cell: thumbnail shows; the block text holds a `data:image/…` URL.
- Enter on the last row, and the **+** row: a new block appears below the last row's block and the row shows at once.
- Formula: `=` then arrow keys / click pick same-row columns; `#ERR` on a cycle.

## v0.2.2: row menu, units, `f`

- Right-click a row: menu appears at the pointer; Delete row removes the block; Ctrl+Z in Logseq restores it.
- Add a row, then type into one of its cells: the row stays (its first line is `row N`).
- Editing a cell: the cell frame itself is the input; no inner box.
- Scroll a long table: the header row stays at the top.
- `power[W]:: 5` shows as `power` / `W · number`; a Logseq property with `[]` in its name is accepted.
- `f` toggles full screen with the table focused and from the page body; Esc no longer leaves it.
